# The 10-to-6 case near crossover 1/4, and balanced at every crossover

The following extends the preceding nine-input theorem in three ways:
- For **arbitrary** ten-input, six-output-bit quantizers, the coordinate benchmark holds throughout the closed interval \(|p-1/4|\le 2^{-12}\). Balance is not needed.
- For **balanced** ten-input, six-output-bit quantizers, the benchmark holds throughout \(0\le p\le1/2\). Here balance means all 64 cell sizes are 16.
- Arbitrary maps are also bounded throughout the low-crossover interval 0 ≤ p ≤ 2⁻¹⁶.

These claims do not rule out an unbalanced ten-input counterexample at another crossover. We work in nats. Write \(C=\ln2-h(p)\), \(J(A)=I(X_A;X_A\oplus Z)\) for uniform \(X_A\) on a cell \(A\) of size \(m\), and use the polarization enumerator justified in **exact-nine.md**.

## Arbitrary maps near crossover 1/4

Use \(\lambda=29/20\). For each cell size \(m<44\) we will certify \(J(A)\ge t_m C\), where \(t_m=4+\lambda(1-16/m)\). For \(m=44\) we check the stronger \(J(A)\ge (4+\lambda)C\), which extends to every \(m>44\) by concavity and mixing the uniform distributions on its 44-subsets. Nonpositive \(t_m\) for \(m\le4\) requires no check. The sixteen-point coordinate 4-face achieves \(J(A)=4C\) at all crossovers and is also handled without computation. All other compressed candidates of \(m=5,\dots,44\) are certified strictly.

**Integer evaluation at 1/4.** The standalone C++17 program **verify-ten-quarter.cpp** enumerates all shifted sets and checks \(H(P_A)-t_m\ln 2-(d-t_m)h(1/4)>12\cdot2^{-12}\) for the nonexceptional cases, where \(d\le10\) is the number of support coordinates (fixed coordinates cancel). Apply integer one-bit kernel \((3,1)\) in each support coordinate to the cell indicator, giving integers \(w_y\) and \(\sum_yw_y=m4^d\). Thus \(H(P_A)=\ln(m4^d)-\sum_y w_y\ln w_y/(m4^d)\). The comparisons use the identity \(h(1/4)=2\ln2-(3/4)\ln3\). The first 17 terms of the binary range-reduced log series and the upper tail \(2z^{35}/[35(1-z^2)]\) are rounded outwards to scale \(2^{50}\). Integer accumulators use signed 128-bit arithmetic. All logs and bounds are conservatively rounded, including the multiplication by \(d-t_m\) if negative. The ten-bit cube has 1024 words, so shifts and index arrays are bounded; width estimates are \(w_y\le4^d\le2^{20}\), \(\ln w_y\) in the integer log scale below \(2^{54}\), and the largest scaled comparison (including the multiplication testing the margin) below \(2^{110}\). The run covered 75,287 shapes including the four immediate cases, and every one of the remaining 75,283 passed the strict test. The output log combines sizes 3–29, 30–39, and 40–44.

**Uniform extension to the interval.** For each fixed cell, \(H(P_A(p))\) is nondecreasing by the BSC semigroup and entropy concavity. On the other hand \(J(A)=H(P_A(p))-dh(p)\) is nonincreasing by the data-processing inequality for the same semigroup. Thus \(0\le H'(P_A)\le dh'(p)\) throughout the interior, and the derivative of the tested entropy gap lies between \(-(d-t_m)h'(p)\) and \(t_m h'(p)\). Both \(t_m\) and \(|d-t_m|\) are at most 10. On the containing interval \([6/25,13/50]\), \(h'(p)\le\ln(19/6)<6/5\); the last inequality follows by the first four terms of the positive exponential series or by the same log bounds. Accordingly the absolute gap derivative is \(<12\). When \(|p-1/4|\le2^{-12}\), the exact gap at \(p=1/4\) exceeds this maximum possible loss. Averaging over \(K\le64\) nonempty cells gives \(I(X;Y\mid U)\ge[4+\lambda(1-16K/1024)]C\ge4C\), and hence \(I(U;Y)\le6C\), as claimed.

**Reproduce.** Build using **g++ -O3 -std=c++17 verify-ten-quarter.cpp -o verify-ten-quarter**, then run **./verify-ten-quarter** without disabling assertions. Optional arguments give the inclusive first and last cardinality. Expected output is in **verify-ten-quarter.log**.

## Balanced maps at every crossover

All cells have size 16, so it suffices to check \(J(A)\ge4C\) for each. There are just 46 shifted shapes; one is the four-face, an equality case at every crossover. The standard-library **verify-balanced.py 10** certifies the other 45 shapes using the Walsh/Parseval upper-noise bound, the directed boundary lower-noise bound, and exact compact dyadic subdivision as described in **exact-nine.md**. For each shape it selects its own upper-noise dyadic cutoff via the proved divergence bound, and its own lower-noise dyadic cutoff via the proved boundary inequality. Across the 45 tested shapes there were 15,455 closed intermediate-interval checks. See **balanced10.log**. This also implies equality only for partitions into coordinate 4-faces at interior crossover, by the strict compression argument.

## Arbitrary maps close to zero crossover

The same argument also covers **every ten-input, six-output-bit map on \(0\le p\le2^{-16}\)**. This time use \(\lambda=10/7\) and the same cutoff of 44. For \(m=16\) use the already-certified balanced cell inequality \(J(A)\ge4C\) (it is a bound per cell, independent of the sizes of the other cells). For every other \(m\le44\), a nonpositive bound is automatic; otherwise the exact size-only verifier **verify-ten-low.py** checks \(\ln m> t_m\ln 2+(10-t_m)h(2^{-16})\). Since \(H(P_A)\ge\ln m\) by concavity under independent noise translations, this proves \(J(A)\ge t_m C\) without shape enumeration. Apply the same 44-subset mixing argument and weighted average as above. The verifier is standard-library Python using the same exact logarithm bounds as the nine-input certificate.

## The obstruction near complete noise

A single-cell affine bound of this form cannot settle the unrestricted ten-input case near \(p=1/2\). Here \(J(A)/C(p)\to10-B_A\) by the quadratic Walsh expansion. For the full radius-one ball in the ten-cube, \(m=11\) and \(B_A=810/121\), so a comparison \(J(A)/C(p)\ge4+\lambda(p)(1-16/m)\) requires asymptotically \(\lambda(p)\ge84/55-o(1)\). For the product of a free bit with a radius-one ball in the nine-cube, \(m=20\) and \(B_A=144/25\), forcing \(\lambda(p)\le6/5+o(1)\). The two conditions are incompatible. This is an obstruction to the local proof method, not a counterexample: the shapes have not been assembled into a partition with a positive overall advantage.
