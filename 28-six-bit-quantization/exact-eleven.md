# Balanced 11-to-6 quantizers, all crossover probabilities

Let \(X\) be uniform on \(\{0,1\}^{11}\) and let \(Y=X\oplus Z\) for independent Bernoulli(\(p\)) error bits. For any quantizer \(U=f(X)\) with exactly 64 equally probable outputs, \(I(U;Y)\le 6(1-h_2(p))\) for every \(0\le p\le1/2\). Equality at interior \(p\) occurs precisely when every cell is a coordinate five-face, possibly with different free coordinates. Unbalanced eleven-input quantizers are not covered.

Each cell has size 32. In nats we need to prove \(H(P_A)\ge 5\ln2+(d-5)h(p)\) after polarization to a shifted set in its support dimension \(d\le11\). This reduction, and strictness unless polarization is by a cube isometry, are proved in **exact-nine.md**. The five-face attains equality. For each remaining shape the standard-library program **verify-balanced.py** selects certified upper- and lower-noise dyadic end caps using the Parseval and boundary bounds in **exact-ten.md**, then covers every intermediate crossover by exact dyadic subdivision with directed integer log enclosures. Run **python3 verify-balanced.py 11** to reproduce; for parallel runs optional shape ranges take the first included and first excluded zero-based lexicographic indices. Every original unshifted cell inherits the bound by polarization. Averaging and adding back the canceled fixed coordinates gives the stated mutual-information inequality.
The run covered all 1791 shapes (including the exact five-face), with 651223 certified closed intermediate intervals for the other shapes. See **balanced11.log**.
