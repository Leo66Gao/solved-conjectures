# Six-bit binary quantization

**Leo Gao** · AI-assisted research · Independent review and priority assessment pending

Coordinate readout is optimal at every crossover for all maps with up to nine input bits, and for balanced maps with ten or eleven input bits. For arbitrary ten-input quantizers with at most 64 outputs it is optimal through $20317/65536$ (about 31.0013% crossover).
