# Six-bit binary quantization

**Leo Gao** · AI-assisted research · Independent review and priority assessment pending

**Partial.** Coordinate readout is optimal for all maps with up to nine input bits, and for balanced maps with ten or eleven input bits, at all crossover rates.

[Nine-input proof](exact-nine.md) · [Eleven-input proof](exact-eleven.md)

These results do not establish six-bit optimality at larger input sizes. The twelve-input search yielded no counterexample. See the dimension-specific proofs for exact reproduction commands and the search note for scope. For comparison, see the [seven-bit counterexample](../15-seven-bit-quantizer/).
