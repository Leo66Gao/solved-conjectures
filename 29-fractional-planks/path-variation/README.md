# Fractional planks by path variation

**Leo Gao** · AI-assisted research · Independent review and priority assessment pending

For packed convex sets in the plane $x+y+az=t$, the fractional cover cost is at least $1-a$. In particular the conjectured $2/3$ bound holds at every feasible offset for $0\le a\le1/3$, with a nonexplicit extension beyond $1/3$. The full two-equal-normal case remains open.
