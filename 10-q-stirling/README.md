# Gaussian limits for q-Stirling coefficients

**Leo Gao** · AI-assisted research · Not peer reviewed

The Gaussian boundary is classified for the four type A and B q-Stirling triangles, including a uniform lattice local limit. Fixed defect gives an explicit beta convolution. The previously known interior result is credited.
