# The classical values of the Fishburn–Reeds Bell matrices

**Leo Gao** · AI-assisted research · Not peer reviewed

The conjectured classical value at diagonal shift 2/3 holds for every projective D-family size. The exact finite shift formula on [0,1] and the optimized asymptotic ratio 79/51 are proved analytically. The latter is specific to this family, not an estimate of the universal Grothendieck constant.
