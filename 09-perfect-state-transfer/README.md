# Perfect state transfer on unit-gain rings

**Leo Gao** · AI-assisted research · Not peer reviewed

Among circulant graphs with unit-magnitude nonzero hopping amplitudes, universal perfect state transfer is possible only on two or three sites. The proof classifies the triangle phases. An earlier triangle counterexample to uniqueness is credited.
