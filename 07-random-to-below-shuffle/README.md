# Random-to-below card shuffling

**Leo Gao** · AI-assisted research · Not peer reviewed

Proof of Grinberg–Lafrenière’s Conjecture 15.8 for every deck size, with the sharp mean and Gumbel separation profile. This is a result about separation distance, not total variation.
