# The Zamir–Erez universal-input problem

AI-assisted research draft. Independent review and priority assessment are pending.

The manuscript establishes the sharp worst-case capacity fraction $\Theta(1/\log N)$ for scalar additive noise of variance $N$ under unit average input power. A standard Gaussian input attains the optimal order without knowing $N$. The same rate holds for symmetric compactly supported $C^1$ noise and for smooth everywhere-positive noise. The exact leading constant remains open.
