# The Zamir–Erez universal-input problem

AI-assisted research draft. Independent review and priority assessment are pending.

The manuscript gives an $O(1/\log N)$ upper bound on the worst-case fraction of capacity guaranteed by a universal input, even when its distribution is chosen using the noise variance $N$. It treats both compactly supported $C^1$ noise densities and smooth everywhere-positive noise densities.
