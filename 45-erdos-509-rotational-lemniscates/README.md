# Disk covers of rotational polynomial lemniscates

**Leo Gao** · AI-assisted research · Independent review and priority assessment pending

A sharp disk-content inequality for power-map inverse images proves [Erdős #509](https://www.erdosproblems.com/latex/509) when the polynomial lemniscate has rotational symmetry of order at least three. The unrestricted case remains open. The main proof includes a matching sharpness construction for the disk-content inequality, not for the universal lemniscate constant.

[Manuscript](power-pullbacks.pdf) · [Proof with context and sources](proof.md). Run `python3 check.py` and `python3 partition-check.py` to reproduce the finite diagnostics.
